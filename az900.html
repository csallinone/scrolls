Cloud concepts

Almost every modern business relies on IT infrastructure. Depending on its needs, size and reach, that can mean anything from a server room to large data centres with powerful computers, storage, networking and security hardware, uninterrupted power, generators, several fail-safes and clustered database servers.

Instead of owning that infrastructure on-premises, with its high CapEx and OpEx, a business can rent infrastructure that it reaches over the internet. That gives three options.

On-premisesThe business owns and runs its own IT infrastructure.
On the cloudThe business rents infrastructure from a provider and reaches it over the internet.
Hybrid cloudA combination of on-premises and cloud infrastructure.
Why the cloud can share hardware: cloud infrastructure is virtualised. A software layer called a hypervisor divides physical datacentre hardware (servers, storage, network) into isolated virtual resources. Businesses can then provision and manage virtual machines, networks and storage without ever touching the physical hardware.

Microsoft (Azure), Amazon (AWS) and Google (GCP) are three globally recognised cloud providers. They operate massive global networks of datacentres, so whether a business needs web hosting, database servers or complex applications, the scalable infrastructure is there to meet almost any goal.

Cloud service types

The service type decides how much you manage and how much the provider manages. Pick a type to see who manages each layer, then read its definition and a real-world case.

Who manages what

    You always manage your own user accounts, licences and who may see your data.

    Definition and example for each type

    IaaSInfrastructure as a Service

    Definition and maintenance

    You rent the raw infrastructure (virtual servers, storage, networks). You are responsible for managing the OS, runtime and applications.

    Real-world example

    Lift-and-shift migration. A company moves its legacy Windows Server 2012 application to an Azure VM. Microsoft manages the physical hardware, but the company must still patch the OS and update the app.

    PaaSPlatform as a Service

    Definition and maintenance

    You rent a fully managed platform (OS, runtime, middleware) to deploy your code. You manage only the application and data.

    Real-world example

    Web app hosting. A startup deploys a Python e-commerce site to Azure App Service. Microsoft handles OS patches and web server configuration, so the developers can focus on pushing new code.

    SaaSSoftware as a Service

    Definition and maintenance

    You use a complete, ready-to-use application over the internet. The provider manages everything: infrastructure, platform and software.

    Real-world example

    Microsoft 365. A corporation uses Outlook for email and Teams for chat. The IT team manages no servers or code, only user accounts and licences.

    Cloud deployment models

    Deployment models describe who the infrastructure is shared with. Pick a model to see its definition and an example.

    Public cloud

    Definition

    Infrastructure is owned by a third-party provider (Microsoft, AWS, Google) and shared securely among multiple unrelated customers over the internet.

    Real-world example

    A startup hosts its new mobile app backend on Azure App Service. It shares the physical servers with other companies but pays only for its own usage.

    Private cloud

    Definition

    Infrastructure is dedicated exclusively to a single organisation, offering maximum control, security and compliance.

    Real-world example

    A hospital builds its own private cloud on-premises to store patient medical records, keeping strict HIPAA compliance and total control over data residency.

    Hybrid cloud

    Definition

    A combination of an on-premises private cloud and a public cloud, allowing data and applications to move between them.

    Real-world example

    A retail bank keeps sensitive customer account databases in its own private datacentre, but uses the public Azure cloud to host its customer-facing website so it can scale in peak shopping seasons.

    Community cloud

    Definition

    Infrastructure is shared by several organisations that have common concerns, such as mission, security or compliance requirements.

    Real-world example

    Several government agencies in the same region share a community cloud to host citizen services, cutting costs while meeting shared, strict security regulations.

    Multi-cloud

    Definition

    Using services from two or more public cloud providers at the same time, to avoid vendor lock-in or to use best-of-breed services.

    Real-world example

    A global enterprise uses Azure for its Windows-based enterprise applications and AWS for its machine learning workloads, so no single provider failure takes down the whole business.

    Core benefits of cloud computing

    Ten benefits the exam expects you to know. Tabs with the same colour belong together: availability and reliability, scale, predictability, security, manageability, and sustainability.

    High availability

    Definition

    Maximum availability of resources regardless of disruptions, backed by Service Level Agreements (SLAs) that guarantee uptime.

    Real-world example

    A hospital's patient portal runs across several servers. If one fails, traffic is rerouted to another at once, so doctors can always reach records (a 99.99% SLA).

    Scalability: vertical

    Definition

    "Scaling up or down." Increasing or decreasing the processing power (CPU, RAM) of an existing resource.

    Real-world example

    An e-commerce company runs a database on a VM. Before Black Friday it scales the VM up from 8 GB to 64 GB of RAM to handle the heavy queries.

    Scalability: horizontal

    Definition

    "Scaling out or in." Adding or removing resources, such as VMs or containers.

    Real-world example

    A video streaming service gets a sudden spike in viewers. Autoscaling adds 10 more web servers (scale out), then removes them when the show ends (scale in).

    Reliability

    Definition

    The ability of a system to recover from failures and keep working, supported by the cloud's decentralised global design.

    Real-world example

    A company hosts its app in two Azure regions. If a hurricane cuts the power in Region A, traffic fails over to Region B with no human intervention.

    Performance predictability

    Definition

    Predicting the resources needed to deliver a good customer experience, using tools such as autoscaling and load balancing.

    Real-world example

    A tax software company knows traffic surges in April. Load balancers spread the traffic so no single server is overwhelmed during the deadline rush.

    Cost predictability

    Definition

    Forecasting or tracking cloud spend in real time, to use resources efficiently and avoid bill shock.

    Real-world example

    A startup uses the Azure Pricing Calculator to estimate monthly costs before deploying, and sets budget alerts that notify it if spending passes $500.

    Security and governance

    Definition

    Using cloud tools, templates and automated patching to meet technical standards and regulations, including DDoS protection.

    Real-world example

    A financial firm uses Azure Policy so no database can be deployed without encryption. The provider automatically blocks DDoS attacks on its public website.

    Manageability of the cloud

    Definition

    Automating the management of resources: autoscaling to need, auto-replacing failing resources, deploying from templates.

    Real-world example

    An IT admin sets a rule: "If CPU is over 80%, add a server. If CPU is under 20%, remove one." The cloud applies it with no manual work.

    Manageability in the cloud

    Definition

    The ability to manage your environment through several interfaces: web portal, CLI, APIs and PowerShell.

    Real-world example

    A DevOps team automates deployments with Azure CLI scripts, while the finance team uses the Azure web portal to read cost dashboards.

    Sustainability

    Definition

    Optimising resource use to cut waste and carbon footprint, in line with green initiatives.

    Real-world example

    A development team schedules all test VMs to deallocate (switch off) overnight and at weekends, saving both money and energy.

    Is this page enough to pass? It is a good map, but not the whole exam. The notes above name many services without explaining them. The ones the exam asks about most often are identity and security (MFA, passwordless sign-in, Conditional Access, external identities, defence in depth, RBAC), governance and cost tools (tags, locks, Policy, Purview, Service Trust Portal, pricing and TCO calculators, Cost Management), monitoring tools (Advisor, Service Health, Monitor), and storage redundancy and tiers. Questions on those topics carry a New topic label, and their explanations are the lesson.
